# ESP32 网页风格面板视觉稿

这是 UI-1 的本地静态原型。无需安装依赖、构建或启动服务；直接用浏览器打开 `index.html` 即可。所有设备名称、目录、端口状态、控制台内容都属于虚构样例，顶部的 `MOCK 演示` 标记持续提示当前来源。

## 浏览与交互

- 左侧图标切换「工作台」「工作区」「控制台」三个视图；顶部品牌标记返回工作台。
- 工作台的「连接设备」与「预览忙碌态」只显示短暂的页面忙碌提示；「运行程序」打开逐次确认样式。
- 工作区视图展示默认策略 `confirm-write`：下载/写入/删除/PID 修改和 REPL 逐次确认；连接、运行与中断按策略执行。下载预览会显示严格备份与失败即停止的提示。
- 「预览下载确认」与「预览下载并运行」分别打开对应的本地确认预览，不会执行设备操作。
- 顶部警示图标、工作区路径菜单和控制台「预览错误状态」展示错误样式。
- 确认框中的取消、关闭、遮罩点击、Esc 都可关闭；「确认演示操作」只关闭弹窗并显示提示。
- 控制台「发送演示命令」只在当前页面追加一行虚构文本；「清空演示输出」只清除页面里的样例行。
- 窄窗口会折叠卡片排列；可用浏览器缩放检查 125% 和 150% 的布局。

页面脚本只在当前文档中切换视图和演示状态。它不请求网络、不连接本机服务、不访问设备或文件、不写入浏览器存储；刷新页面会恢复初始状态。

## 紧凑单页评审稿

`compact.html` 是按 UI-7 反馈制作的独立紧凑单页：常用连接与程序操作同屏，串口控制台常驻，高级设置默认收起。串口文字支持鼠标选择和 `Ctrl+C`，控制台标题栏提供“复制输出”按钮。单独打开预览时，操作按钮只追加 MOCK 演示文字；产品宿主 `panel.launcher --ui web --mode mock` 还会内联加载 `compact_live.js`，从共享 mock 后端读取快照并调用固定面板 API。

在包含 `pywebview==6.2.1` 和 WebView2 Runtime 的 Windows Python 环境中，可运行 `preview_compact.py` 以打开 450×500 的独立窗口。窗口使用自绘无边框标题栏，品牌区可拖动窗口，右侧的最小化与关闭按钮只控制当前预览窗口。预览把 CSS/JS 内联到内存页面，不开启 HTTP 服务，不调用现有面板、broker、bridge、串口或设备。

## 文件

- `index.html`：页面结构与模拟数据。
- `styles.css`：颜色、排版、组件状态与窄窗口适配。
- `script.js`：仅用于原型内部的视图切换、确认框和临时状态展示。
- `compact.html`、`compact.css`、`compact.js`：紧凑单页 MOCK 初稿。
- `compact_live.js`：仅由可信的 WebView 宿主内联加载；将紧凑页面接到共享 MOCK 快照和有限的面板操作 API。
- `preview_compact.py`：将紧凑稿作为可信本地资源内联，并打开独立 WebView2 评审窗口。
- `verify_copy_ui7.ps1`：在可见预览窗口中验证复制按钮和鼠标选中后 `Ctrl+C`。
