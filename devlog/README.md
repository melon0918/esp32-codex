# 每日开发日志

每个自然日使用一个 `YYYY-MM-DD.md` 文件，日期按 Asia/Shanghai。日志包含“完成事项”“验证与证据”“问题”“待办”。已完成事项只能来自当天可核对的文件改动、测试结果或明确决策；无开发活动时写“无新增开发”。待办从前一日志延续并按当前执行计划更新。

每天 23:00 自动检查本项目目录，追加或更新当天日志。自动任务不执行开发、不操作串口或实体设备，也不把未验证工作写成已完成。重复运行应更新同一天文件，避免重复条目。

日志模板：

```markdown
# YYYY-MM-DD 开发日志

## 完成事项
- 无新增开发。

## 验证与证据
- 无。

## 问题
- 无。

## 待办
- 按 docs/implementation-plan.md 的当前阶段推进。
```
