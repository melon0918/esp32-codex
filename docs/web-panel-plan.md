# 网页风格面板开发计划

2026-09-26 用户反馈现有 Tk 面板仍有明显原生 Windows 表单感，要求先制定重设计计划。本计划是 [当前计划](plan.md) 步骤 10 的界面分支。2026-09-28 用户授权真机联调和自由测试，进入 UI-10 真机交付。

## 目标与边界

- 保留独立 Windows 小窗口、Codex 对话打开入口和开始菜单入口；重复打开只显示同一窗口。窗口与 Codex 仍通过现有 broker 共享唯一桥、状态和控制台。
- 页面呈现使用 HTML/CSS 风格，默认采用浅色、克制的开发工具视觉：清楚的中文字体、较少的强调色、可辨认的模拟/真实来源、足够大的点击目标。先以约 700×700 的并排窗口设计，并检查窄窗口及 Windows 125%/150% 缩放。
- 信息顺序：顶部展示工作区、设备连接和模拟来源；常用连接/运行操作置于主视图；控制台可展开；工作区、策略、下载放在次级区域。危险动作不因视觉简化而隐藏其目标、影响和确认步骤。
- mock 用于原型与回退；个人正式安装使用真实桥，但启动不自动连接串口。窗口仅确认自身发起的动作，不能批准 Codex 对话动作。严格备份、校验、工作区锁、DSH 不抢占和设备停止语义均不改。
- 保持当前命名管道架构，不开放 HTTP/WebSocket 或其他网络监听。网页内容只从可信的本地打包资源加载；页面不直接持有 broker 令牌、管道句柄或任意文件/命令执行能力。窗口宿主只向页面提供有限的状态快照与明确的面板操作入口，并在宿主侧复核参数、状态与确认。
- 新面板验收前保留 Tk 版本与现有启动行为；不得覆盖个人已安装副本或将静态视觉稿称为可操作产品。无实体板卡时只以 mock/假桥验证。

## 分阶段实施

一次只推进下表一个阶段。每阶段开始前先在当日日志记录目标和验收标准；主 Agent 独立审查、复核证据并更新状态后再进入下一阶段。

| UI-2 窗口宿主验证 | 在 Windows 独立窗口加载打包的本地页面；验证页面与 Python 宿主间的最小双向消息、生命周期和运行依赖 | 无网络监听；页面不能直接访问 broker 凭证；窗口关闭释放自身资源；记录运行时、打包体积、缺失依赖时的处理及截图。若候选宿主不满足条件，先修订技术方案，不进入 UI-3 | 已验收：2026-09-26，独立 pywebview/WebView2 mock 宿主及临时资源包通过 |

## UI-10 真机版交付

个人安装、MCP 启动器和紧凑网页面板切到真实桥，面板与 Codex 工具共享同一 broker。Connect 由用户显式点击；严格备份和工作区策略不变。保留 mock Web 与 Tk 回退。

已完成：个人开始菜单主入口启动真实 Web 面板；MCP `esp32_open_panel(ui="web")` 返回 `simulated=false`、`autoConnect=false`；mock Web/Tk 回退保留。通过安装包真实 MCP ClientSession 发现 26 个工具，并在 COM4 上连接、读取 MicroPython 状态、断开；最终状态 `connected=false`。未执行板载文件操作、REPL 或程序运行。桥的 `physicalStopConfirmed=false`，设备物理停止不作为验收通过项。本机 Windows 前台窗口截图未能从当前 WSL Computer Use 会话取得，因此不把本步骤记作像素级目视验收。

个人包、Codex CLI 刷新、测试和真机证据见 [2026-09-28 开发日志](../devlog/2026-09-28.md) 与 [当前状态](status.md)。

## 技术决策点

UI-1 只决定界面语言和交互层级。UI-2 已在 Windows 以 pywebview 6.2.1 和本机 WebView2 Runtime 154.0.4258.37 验证内存页面、双向固定演示消息和关闭退出。原型代码见 `../web-panel/host/`，没有接入 PanelBackend；UI-3 才开始只读接入。页面从可信本地 HTML/CSS/JS 内联，不启动 HTTP 服务；临时复制的 7 文件资源包也可独立启动。该技术选择仍需 UI-5 验证正式安装包和双入口。若后续实现必须借助本地 HTTP 服务或外部浏览器，先更新 [架构](architecture.md)、[技术规范](standards.md) 和安全审查；不可把网络入口作为隐含实现细节。

## 实机试点

真机面板启动后只读取端口、状态与控制台，不会自行连接；Connect、控制、REPL 与写入由用户在面板或 Codex 工具中显式触发并沿用现有策略。已有 COM4 真实桥只读试点通过；UI 阶段的 mock 截图和测试不能代替实机证据。

## UI-7 初稿约束

页面沿用现有浅色紫色强调与深色控制台视觉。首页直接展示工作区、串口选择/连接、入口程序、运行/中断/停止、下载/下载并运行、常驻控制台及单行 REPL；工作区发现/认领与策略细节置于一个默认收起的高级区域。实际操作逻辑与安全门禁不在本轮修改范围内。

窗口顶部已改为无边框自绘标题栏，品牌区是拖动区域；最小化与关闭按钮由预览宿主提供两个固定窗口操作，不暴露其他页面宿主能力。最大化按钮不展示，以保持紧凑窗口结构。
